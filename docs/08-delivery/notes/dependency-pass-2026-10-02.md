## What changed

### `package.json` — npm `overrides` (patch/minor within the 8.x / 1.x / 0.35 line)

```json
"overrides": {
  "brace-expansion@1": "1.1.21",
  "brace-expansion@5": "5.0.12",
  "js-yaml@4.3.1": "4.3.2",
  "postcss@8.4.31": "8.5.23",
  "sharp@0.34.5": "0.35.4"
}
```

- **brace-expansion** 1.1.18 → **1.1.21** (via minimatch@3) and 5.0.9 → **5.0.12** (via minimatch@10,
  from `@typescript-eslint/typescript-estree`) — patch fixes.
- **js-yaml** 4.3.1 → **4.3.2** (via `@eslint/eslintrc`) — patch fix.
- **postcss** 8.4.31 → **8.5.23** for **next's own pinned copy only** (`postcss@8.4.31`), a minor
  within PostCSS 8 (API-compatible). Next 15.5.24/25/26/27 all still pin `postcss@8.4.31`, so the
  only non-major fix is this override; the vitest→vite copy stays at 8.5.26 untouched.
- **sharp** 0.34.5 → **0.35.4** — within next's own `optionalDependencies` range
  (`^0.34.3 || ^0.35.3` on 15.5.24, widened to `^0.34.3 || ^0.35.4` in 15.5.25+), so this is the
  range Next itself allows, not a forced major.

`package-lock.json` regenerated by `npm install` (adds sharp 0.35.4's optional platform packages;
no other dependency graphs moved).

### `.agents/skills/processing-s3-uploads-with-step-functions/scripts/requirements.txt` — pip

`urllib3==2.7.0` → **`urllib3==2.8.0`**, with the two SHA-256 pins re-read from the PyPI JSON
project metadata for 2.8.0 (wheel + sdist); boto3/botocore and the rest of the hash-pinned set are
unchanged (boto3's own `urllib3 < 3` constraint is satisfied). The skill's `skills-lock.json`
hash covers `SKILL.md`, not this file, so the vendored lock is unaffected.

### What changed

`package.json`:

```diff
-    "vitest": "^3.1.0"
+    "vitest": "^4.1.11"
...
```

`package-lock.json` regenerated by `npm install`: vitest and the whole `@vitest/*` family

npm pulling the new vite 8 major in the same step. The vite entry is unchanged (7.3.6).

`strip-literal`, `cac`, `loupe`, `pathval`, `check-error`, `deep-eql`). **No runtime
dependency moved — all of it is dev/test-only.**
