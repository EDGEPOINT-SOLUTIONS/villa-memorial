Standing Rules Through September

  1. Friday demo is mandatory and integrated — trunk must run all green scenarios so far.
  2. Contract changes after Aug 31 require producer + consumer sign-off (Keb arbitrates). Cross-track contracts frozen in W1: fulfillment event schema (Keb→Jawi), availability service interface (Jawi→Gab), GeoJSON map API (Jawi→Gab), order/payment/case APIs (Keb→Gab).
  3. System specs ship with every feature card before its Friday demo — no exceptions given no dedicated QA staff.
  4. Risks: bus factor = 1 per domain → pair on cross-track changes, no private branches older than 2 days. Keb is the overload point → pre-need (E) and AI (L) are the designed pressure valves.
  5. Staging deploys daily from Aug 31; production deploy rehearsed once before Sep 28.
