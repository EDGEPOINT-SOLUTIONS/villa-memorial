Alignment audit · captain's review

Is villa-memorial still following the IN MEMORIAM PRD?

An honest read of everything built in this repo against the in-memoriam PRD: what is in line and why, what is an honest placeholder, what is missing, and what we built that the PRD never asked for.

Audited commit f2ce5c7 (PRs #38 + #40; project main is one commit ahead at ab0a70f) PRD: /home/gab/firstmate/projects/in-memoriam/docs 2026-09-17 805/805 tests green · 99/99 routes rendered 200

Verdict: yes — in line, and honest about the gaps.

The frozen architecture is followed (Next.js BFF per ADR-003/004, frozen lot/case/order/booking/document contracts, scope-gated RBAC, tokens-only styling), the client's real 2026 prices and papers drive the storefront, and every screen without a live service says so in designed wording instead of faking data.

Where we are not in line: 20 PRD screens are not built (mostly blocked on unbuilt services), 25 are honest placeholders naming their blocker, and the repo has grown 13 captain-approved extensions the PRD screen inventory never named — the 3D park, the agent portal, the admin stores, the sky/navy/gold palette. None conflicts with a PRD rule, but the PRD no longer describes the whole shipped surface, and that drift is the thing to manage.

Defects found: four staff screens render a 403 to the admin because their scope tokens are malformed — the honest placeholder exists, it is just gated by the wrong word. Two villa docs describe a pre-portal build.

Reason: the cross-track plan is contract-driven and several services are unbuilt. Consequence: every portal demos standalone; live branches are real where contracts are frozen (property, cases, billing, auth, audit, documents, ordering) and honest 503 where they are not.

Reason: jwt-claims-v1/rbac-scopes-v1 define scopes only (customer holds catalog:read + tenancy:modules:read; agent holds orders:*, property:read, catalog:read). Consequence: lib/auth/destination.ts infers the portal from scope heuristics; four doors exist; the family room has no scope of its own.
