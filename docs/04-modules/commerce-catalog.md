# Commerce & Catalog

## Catalog as authoritative source
The catalog is the single source for what the business sells, rents, schedules, reserves, or quotes.
Same catalog/pricing data feeds public website AND internal operations.

## Item detail fields (blueprint §7)
Name, SKU, category/subcategory, description, media, regular/promo/cash price, installment price &
terms, duration, availability status, included/excluded items, optional add-ons, requirements/
documents, booking requirement, fulfillment type, T&C, FAQ, Buy Now / Add to Cart / Request Quote.

## Smart Service Builder / configurator (blueprint §8)
- Ask what customer needs: immediate assistance / plan ahead / memorial lot / specific service / product
- Identify what family already has (casket, chapel, lot, vehicle, embalming…)
- Build customized arrangement from independent services; recommend missing/compatible items without forcing
- Live estimated total; add/remove/replace; respect inventory/resource/scheduling constraints
- Converts to cart/order; AI may assist but never overrides business rules

## Unified commerce/cart engine (blueprint §9)
- Mixed carts: products + services + rentals + scheduled services + property reservations + add-ons (+ plan subject to contract rules)
- Quantity, duration, date/time, resource, location attributes
- Price calculation via rules engine; discounts/promos; fees/taxes
- Availability validation; temporary holds for scarce resources during checkout; cart expiration
- Quote-required items create lead/quote instead of immediate payment
- Three primary transaction types: At-Need Order / Pre-Need Contract / Memorial Property Transaction (+ Service-Only pattern)

## Availability & resource booking engine (blueprint §10)
Real-time chapel/viewing room/hearse/staff/embalmer/team/cremation facility/lot/equipment
availability · prevent double booking · temporary holds with expiry + auto-release · conflict
detection · calendars by resource/branch/staff · utilization reporting.

## CRM, leads & sales pipeline (blueprint §33)
Lead sources: website, Facebook, Messenger, walk-in, referral, phone, agent, event, ads, + configurable.
Pipeline: New → Contacted → Qualified → Presentation → Proposal → Reserved → Sold.
Opportunities, follow-ups, appointments, activity history, agent assignment, conversion, revenue &
campaign attribution.
